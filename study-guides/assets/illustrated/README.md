# Class infographic artwork

The digital study guides use **five infographics per class guide**, with 25 distinct final illustrations. They were created and corrected with the **built-in OpenAI image generator**, then encoded as WebP for web delivery at their original dimensions. Translated titles, numbered explanations, model responses and exact interactive diagrams are rendered by the study guide rather than embedded as English text.

Final assets are the `.webp` files in this directory. [Final prompts](prompts.json) include the last correction prompt where one was used; [revision prompts](revisions.json) record those targeted changes. Original full-resolution PNGs are retained locally under `output/study-guide-art-originals/` and in the image generator output directory.
