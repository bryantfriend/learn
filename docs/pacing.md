# Lesson pacing

The teacher player now uses a **40-minute core**. The old automatic practice stages are removed from normal navigation. Assessments retain their original structure. Extra time is genuinely additional: choose two five-minute games for 10 minutes, three for 15, or four for 20.

**Extra time** replaces Practice overview with four activities:

1. **Finger vote:** think privately, vote with one or two fingers, explain, reveal, discuss and re-vote.
2. **Teacher mistake:** diagnose and repair a deliberately wrong response; suggest a clue to prevent the error.
3. **Memory detectives:** study the supplied source, hide it, reconstruct details and a connection, then check. Partners can give clues without saying the main word.
4. **Change a condition:** decide what would make an alternative reasonable, or explain why it is impossible. Return to the original case afterwards.

Each activity includes context, a concealed explanation, follow-up prompts and five-minute running notes. Geography questions use the topic bank; GP also includes short new topic-related cases. Spend time on explanations instead of rushing every round. These are informal checks, not stored scores.

Opening Extra time pauses the core timer. Closing returns to the same step without marking work complete. Old checkpoints reset where the changed sequence makes them invalid; class identity and preferences remain. See [Geography workshops](geography-workshops.md) for the redesigned teaching sequence and curriculum limits.
