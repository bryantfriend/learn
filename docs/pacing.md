# Lesson pacing

All 269 curriculum teaching lessons now include two five-minute practice stages in normal Next-stage navigation, before the final reflection. The full sequence contains about **50 minutes of material**. Teachers can use one practice stage for about 45 minutes or both for about 50; timings are estimates, not mandatory waiting periods. Attendance and announcements are separate. Assessment sessions and classroom-routine introductions retain their original structure.

Practice activities include the source on reading slides, followed by a task with a visible outcome. Most lessons ask pupils to improve an evidence-based explanation and then create and solve a source-based challenge. Grade 8 GP Lesson 2 has stock and supply-chain cases; 7A GP Lesson 2 has majority/fairness and canteen-evidence challenges. The Practice overview button previews the same included tasks; it is not additional time beyond the 50-minute sequence.

The existing shorter openings, evidence recording, independent work, peer review and comparison steps remain. Source reading and practice each have their own timer. Teachers can jump past a practice stage using the stage selector while keeping the final reflection. Updated content revisions restart outdated slide checkpoints so the new stages are not silently skipped.
