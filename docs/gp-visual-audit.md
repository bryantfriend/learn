# Global Perspectives visual and teaching audit

204 sessions audited; 189 teaching/review sessions have an interactive SVG model and 15 assessment sessions have procedure guidance without a model.

Models occupy 2–4 minutes of an existing activity. They are explicitly fictional skill demonstrations; the source/task panel transfers the method back to the actual lesson. Existing workbook references, core content and assessments are retained. Ten model families are reused intentionally; this update does not remove repeated curriculum topics. Motion is optional and respects reduced-motion settings.

Teacher tools now provides objectives, the actual lesson sources/tasks, stage timing and notes, model explanations, misconceptions, support and challenge. Shared-screen answer sections start collapsed.
