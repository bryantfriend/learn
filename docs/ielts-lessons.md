# IELTS Preparation for 7A and 7B

Open **Choose class & lesson → 7A or 7B → IELTS Preparation**. Choose any of the 30 numbered lessons. The same material appears for both classes, with separate saved progress. The two existing shared starter lessons remain available.

Each lesson has a planned 45-minute route: connect (5), strategy (8), worked example (8), practice and transfer (14), check and improve (7), exit ticket (3). Timings are estimates. Use notebooks and the classroom board; no student devices or external recordings are needed. Reveal model answers only after pupils attempt the task. Read the listening scripts in the relevant stage’s teacher notes before class; those notes become visible to the class when opened on the board. Keep scripts concealed during listening.

The lessons are original IELTS Academic foundation activities adapted for Grade 7. Short tasks scaffold exam skills and do not constitute full official papers or predicted band scores. Writing extensions can build towards the official response lengths. The final lesson is a shortened diagnostic circuit.

| Lessons | Focus |
| --- | --- |
| 1–5 | Exam orientation, instructions, paraphrasing, vocabulary, grammar |
| 6–11 | Listening details, prediction, distractors, maps, multiple choice, notes |
| 12–18 | Reading main ideas, scanning, True/False/Not Given, views, matching, summaries, time management |
| 19–24 | Speaking familiar topics, communication repair, long turns, stories, opinions, pronunciation |
| 25–29 | Academic Writing charts, trends, maps/processes, arguments and essay instructions |
| 30 | Four-skill practice and an individual improvement plan |
