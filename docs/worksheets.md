# Optional printable worksheets

Every lesson's **Teacher tools → Optional worksheets** offers:

- **Print lesson worksheet**: the lesson investigation or practice tasks, with sources and answer/drawing space.
- **Print homework worksheet**: short independent practice questions with their necessary context and space to explain answers.

Each opens a separate preview tab. Choose **Print / Save as PDF** there. Nothing prints automatically, no homework is assigned automatically, and opening/printing a sheet does not change lesson progress or introduce a completion requirement. The normal lesson remains usable without worksheets.

Geography class sheets use the revised investigation tasks and supplied sources. Other classes use the lesson's source/practice material. Workbook-trial sheets provide additional teacher-created research activities; their homework does not require the book. Assessment links provide separate revision from earlier teaching, or a starting-point reflection before a baseline, rather than exposing assessment answers.

The layout supports A4, uses browser pagination, hides screen controls when printed, and includes name/class/date fields. Longer lessons may need more than one printed page; preview before printing. Answer keys and teacher notes are excluded. The sheets load from current classroom lesson data, including compatible local text edits, rather than a separate stale export.
