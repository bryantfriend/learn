# Grade 8 playable lessons and printable assessments — v1.4.0

All 43 long-term-plan entries now open in the existing player: 36 unit lessons, two skills/portfolio reviews and five assessment sessions. The two original shared starters remain available. Grade 8 content is filtered by quarter and remains available only under Global Perspectives.

## Teaching lessons

Each teaching lesson has six stages totalling 40 minutes: notice/question (4), examine evidence (8), model reasoning (6), apply/discuss (10), check understanding (8), reflect/finish (4). Each has a topic-specific case, two source cards, worked reasoning, an application task, a four-option check with a rationale, an open transfer check with a suggested answer, and teacher notes. Challenge lessons use roles, evidence and a recommendation rather than a timed quiz.

The sources and numerical examples are original, explicitly fictional teaching materials. Named locations such as Bishkek are used for imagined scenarios, not claims about actual local conditions. Source-plan titles, objectives and codes are retained. No external worksheets, live AI tools, internet research or unsupplied textbook passages are required. Notebook or oral responses work. The optional mini-inquiry can be practised with the supplied simulated tally list; actual observations need teacher permission and privacy safeguards.

Saved progress, reveals, timers, discussion markers, stars and summaries use the same player as existing lessons. Weekly capacity remains flexible; repeat or extend sessions when the timetable permits.

## Assessments

A0 baseline, Q1, Q2 mid-year, Q3 and Q4 final each have 16 questions with exactly four choices and one best answer. Each includes four fictional source sections and is self-contained. Questions cover numerical interpretation, source evaluation, perspectives, arguments, actions, ethical research and reflection. Correct answer positions are balanced across A–D.

Student papers and teacher keys are separate views at exams/?id=A0 (or Q1/Q2/Q3/Q4); add &key=1 for the key. Each prints as four A4 pages. The print toolbar is excluded from print output and student papers contain no rendered answers. Every key supplies the correct letter and a rationale. Award 1 mark per correct answer, no negative marking, total 16. No grading thresholds or student data collection are added.

The 40-minute assessment session allows 4 minutes for instructions, 30 for independent work, 4 for collection/reflection and 2 to finish. Teachers may adapt access arrangements. MCQs assess reasoning about collaboration and communication, not observed performance; use the teaching challenges for that evidence. These are teacher-created classroom assessments, not official Cambridge exams.

To print: open an assessment, click Open printable student paper, then Print / Save as PDF. Print the teacher key separately from Teacher tools or the print page's key link. Check paper size A4 and disable browser headers/footers if the browser adds them.
