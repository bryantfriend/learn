# Lesson scenario illustrations

Sixteen original AI-generated 3D cartoon scenes, created for Learn in September 2026: factory, playground, canteen, library, city, river, glacier, energy, digital, research, transport, farm, fieldwork, weather, wellbeing and market. Images are delivered as WebP.

They provide visual context for example and practice slides. They are not numerical evidence; the written source supplies exact facts and quantities. Existing instructional diagrams retain priority. Selection and accessible descriptions live in src/lesson-illustrations.js. Student guides share these assets and translated descriptions.
